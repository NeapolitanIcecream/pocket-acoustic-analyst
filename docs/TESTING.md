```sh
make build
make test-core
make test
make analyze
make lint
```

UI 测试使用 `-demoMode` 注入确定性音频和位姿，覆盖：

1. 首页从用户问题进入，不以仪器名称作为入口。
2. 权限解释、录制和持续低频检出。
3. 1 个起点、2 个候选实测点、每个候选后的起点复测和实测点建议。
4. 调整前、一次调整、调整后和变化判定。

## 自动化证据的边界

- 合成正弦和噪声可以验证数学标度、频率估计和失效门槛，不能代表 iPhone 麦克风频响。
- 模拟 AR 位姿可以验证 epoch、闭合和排名规则，不能代表真实房间中的跟踪漂移。
- 模拟器构建可以验证 iOS API 编译，不能代表音频路由、中断、数据源或实时回调性能。

| 路由变化 | 录制中切换内置、USB 和蓝牙输入 | 当次测量无效；不生成分析结果 | 未执行 |
| 外接多通道 | 使用可控双通道接口输入同相和反相信号 | 元数据标记通道 0；不进行波形平均 | 未执行 |
| 系统中断 | 录制时模拟来电/Siri、进入后台，并测试媒体服务重置 | 当次测量无效；下次可恢复 | 未执行 |
