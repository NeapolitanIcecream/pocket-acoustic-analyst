# 从 P0 到产品愿景

## 当前覆盖

| Proposal 能力 | 当前状态 | 边界 |
| --- | --- | --- |
| 测量音频采集 | 已实现 | 内置麦克风真机通过；外接路由与中断矩阵未完成 |
| 10–500 Hz 低频分析 | 已实现 | 未校准，只报告同一设备的相对量 |
| 时间变化与音调分析 | 部分实现 | 20 秒内可分六类声音；还没有 5–30 分钟事件时间线 |

## 当前阶段：验证设备状态调查

真实房间的三次连续测量在约 54 Hz 稳定音和以约 216 Hz 为主的多音调之间变化。这说明单次 20 秒结果有用，但不足以回答“哪项设备状态值得继续检查”。当前软件垂直切片已经实现：

1. 从稳定音或多音调结果进入一个用户命名的设备状态调查。
2. 固定手机位置、方向、AR epoch、音频路由和分析配置。
3. 对齐最多四个候选频率组，并同时跟踪至少三个不重叠参考频段。
4. 按 `A0-B1-A1-B2-A2-B3-A3` 完成三轮夹测；跨次路由或位置参考改变会立即停止。
5. 用联合重采样区分目标频率变化、所有频率共同变化和统计证据不足。
6. 结论只使用“与这次状态变化重复同步”或“没有稳定同步”，并明确不能证明设备是声源。
7. 保存完整调查、逐轮证据和 schema v1→v2 迁移结果，不保存原始录音。

软件门槛由合成测试及模拟器、真机上的确定性 UI 流程覆盖。进入下一产品阶段前仍需：在同一真实房间选择一项可控状态完成三轮；确认变化频率与未变化频率分离；故意破坏一次恢复、路由或位置条件并观察即时拒绝；让非声学用户复述“同步只是线索，不代表设备发声”。单手机仍无法排除每个 B 时段都恰好发生的其他负载变化，因此这类结论不会高于中等可信度。

## 随后实施：长时观察

- 支持 5、15、30 分钟前台观察，使用增量分析和有界环形缓冲，不保留原始录音。
- 把稳定段、启停、间歇段和频率漂移转换为事件时间线。
- 显示“每隔多久出现”“一次持续多久”“主要频率如何变化”。
- 明确录音指示、取消、锁屏和来电行为；后台录音不应默认开启。
- 用 Instruments 验收 CPU、内存、温升、音频丢帧和连续多次测量。

这一步完成后，20 秒内没有稳定音调的场景仍可通过设备周期获得证据。

## 空间能力强化

- 对同一候选位置跨时间重复两次，并改变测量顺序；单次 A-B-A 继续最高中等可信度。
- 增加实体参照或支架提示，减少声学低谷附近的厘米级复位误差。
- 支持用户选择一个已经验证稳定的目标频率，不在多音调场景中自动挑选。
- 外接参考麦克风可同时监控声源时间变化时，再考虑提高空间归因可信度。
- 空间插值只能作为标明的不确定预测层，默认推荐仍来自实测点。

## 房间尺寸与模态解释

先支持手动输入长、宽、高，再为支持设备增加 RoomPlan。理论频率匹配只能作为一条证据；至少还要结合多个空间点的重复分布和目标稳定性。用户文案应为“与该方向的低阶房间模态接近”，不能写成“已找到驻波节点”。

## 振动与衰减功能

### 振动

iPhone 公共 Core Motion 单样本速率通常最高约 100 Hz，约 53 Hz 已接近或超过可用 Nyquist 范围。若加入内置传感器分析，频率上限应为 `min(40 Hz, 0.4 × 实测采样率)`。更高频率需要经过验证的外接传感器；声音与振动同频也只能支持“可能有关联”。

### 房间衰减

先实现带质量门槛的引导录制和相对衰减分类，再评估 EDT、T20、T30 或近似 RT60。必须验证手机扬声器、麦克风自动处理、环境底噪和激励信号，不能把未经控制的拍手录音包装成标准测量。

## 上线前工程与硬件门槛

- 用受控参考信号验证 10.1、53.17、499.7 Hz 和 6 dB 相对步进。
- 覆盖至少两款 iPhone、内置/USB/蓝牙路由、反相双通道、系统中断和媒体服务重置。
- 把外接多通道改为逐通道分析后在线性功率域组合，不做波形平均。
- 用标注的机械声、宽带噪声、音乐和语音场景评估六类声音的混淆矩阵。
- 验证动态字体、旁白、窄屏标题、暗色模式和较长中文文案。
- 为归档增加显式迁移测试和用户可控的删除、导出与隐私说明。

## 明确不做

- 不根据单个频率直接给出空调、风机或电脑的设备名称。
- 不在未经校准时显示绝对 dB SPL。
- 不把理论模态频率接近当作房间传播的证明。
- 不使用 iPhone 扬声器实现主动低频抵消。
