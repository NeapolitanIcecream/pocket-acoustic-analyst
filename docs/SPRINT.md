# Pocket Acoustic Analyst 进度与验收契约

## 目标与成功证据

交付一个可构建、可测试的 iOS P0 应用。没有声学背景的用户应能完成以下闭环：

1. 选择“持续嗡声”问题并按提示录制环境声音。
2. 获得主要低频、持续性、谐波证据、置信度和下一步建议。
3. 围绕同一目标频率采集多个带空间位置的测量点。
4. 从实际测量点中找到较低能量区域，并看到相对改善量。
5. 对一次调整做前后复测；应用应区分“改善”“变化不明确”和“环境不可比”。

成功需要同时满足：

- 工程可由仓库中的声明式配置重建，并在当前 Xcode 工具链通过 Debug 构建。
- DSP 对合成信号的频率、幅度差、谐波和持续性判断通过确定性测试。
- 引导流程、空间扫描、安静点选择和前后对比可在模拟器通过可重复的演示输入执行。
- 真机服务使用实际采样率，处理权限拒绝、中断、音频路由变化和 AR 跟踪质量下降。
- 普通用户界面默认不暴露 FFT、STFT、SPL、RT60 等仪器术语。
- 未校准结果只表达相对变化，不冒充绝对声压级或确定的声源诊断。

## 范围、默认值与不变量

- P0 包含音频采集、10–500 Hz 分析、时间切片、音调与谐波检测、空间扫描、安静点和前后对比。
- 默认测量约 20 秒；分析窗口和刷新策略可配置，测试使用较短输入。
- 相对电平按同一设备、同一会话、同一分析参数比较。
- 空间建议优先从已经测量且质量合格的点中选择，不把插值预测伪装成实测结果。
- 每个空间候选点后必须立即回到起点复测；目标声音变化、相邻起点不闭合或 AR 坐标不闭合时，不生成该轮空间排名和距离结论。
- “可能来自持续机械设备”“空间分布与房间模态相符”只能作为带置信度的解释，不作为声源或传播路径定论。
- 数据默认仅保存在设备本地；本阶段不增加账号、云同步或遥测。
- 工作默认最低系统版本为调研后能兼顾现代 API 和设备覆盖的版本；确定后记录在架构文档。

本阶段不包含绝对 SPL 校准、RoomPlan 房间建模、房间模态匹配、振动联合分析、脉冲响应、主动降噪、云服务和 App Store 发布。它们不能替代 P0 闭环，也不是本次完成门槛。

## 不算完成的结果

- 只有首页、静态原型或演示截图。
- 只有实时频谱，没有面向问题的解释、空间步骤和验证步骤。
- 只用固定假数据证明算法准确，或者只在单元测试中存在而 App 无法调用。
- 把 FFT bin 中心当作精确主频，没有亚 bin 估计或误差测试。
- 推荐一个未测量位置，却没有明确标记为预测。
- 环境明显变化时仍给出确定的前后改善判断。
- 真机 API 编译通过，但音频生命周期、权限或 AR 失败没有用户可恢复状态。

## 乐观前提

本冲刺假定上述完整 P0 在边界内可以实现。该假定用于持续选择面向目标的行动，不作为候选实现正确的证据。

- 依赖选型优先 Apple 官方框架或维护活跃、版本明确、许可证兼容的成熟库。
- 技术事实以 Apple 文档、标准或依赖项目的官方仓库和发布说明为主；产品措辞以提案和本契约为准。

- 没有用户规定的最短时长或调用数；只记录改变产品结果或技术决策的实质工作。

## 失败模型与检查

| 风险 | 可推翻候选实现的检查 |
| --- | --- |
| 采样率被写死导致频率错误 | 用 44.1 kHz 和 48 kHz 合成音分别验证 |
| 短窗或泄漏把主频判断错 | 测试非 bin 中心频率、噪声和相邻双音 |
| 瞬时声音被当成持续嗡声 | 比较持续音、短脉冲和频率漂移输入 |
| 弱泛音被误分组，或把独立音调当泛音 | 测试缺失基频、非整数频比和噪声底 |
| 不可比测量仍宣称改善 | 改变目标频率、稳定性或质量，预期“无法判断” |
| 安静点由坏点或插值幻觉产生 | 注入低质量极值点，确保不会被推荐 |
| 无权限或 AR 跟踪失败造成死路 | 服务错误注入和 UI 测试必须给出恢复动作 |
| 未校准值被误读为绝对 SPL | UI 文案和数据模型不得生成 dB SPL 声明 |
| 模拟器成功掩盖真机路径缺陷 | 真机服务单独编译；所有硬件边界通过协议可替换 |
| 声源随时间变化被误判为空间差异 | 每个候选采用起点—候选—起点夹测；仍只给中等可信度并披露单手机限制 |

## 2026-08-08 14:47 - 低频分析路线通过首轮检验

方法：Accelerate `vDSP.DiscreteFourierTransform`、Hann 窗、线性功率时间平均、对数谱抛物线插值和逐帧持续性检查。

行动：实现 10–500 Hz 分析、动态采样率、亚 bin 主频、局部突出度、谐波组合、竞争音调、频率漂移、时间切片与质量原因。

证据：iOS 18.6 模拟器上的 9 项 DSP 测试在 2.1 秒内通过。53.17 Hz 在 44.1 kHz 与 48 kHz 下误差均小于 0.2 Hz；半幅输入相对差在 6.0206 dB 的 0.15 dB 内；短瞬态、50–60 Hz 漂移和白噪声均未被报告为稳定嗡声。

决策变化：采用 Apple Accelerate 薄层。退役完整 AudioKit 依赖路线，因为通用 tap 的逐帧归一化不满足跨位置和前后相对比较，持续性、谐波和置信度仍需产品领域层。

审查影响：空间扫描加入强制起点复测；后续振动功能不得复现提案中的 53.2 Hz iPhone 加速度示例。公开 CoreMotion 单样本上限约 100 Hz，该频率位于或超过 Nyquist 边界，本次 P0 已排除振动分析。

下一步：集成音频会话生命周期和三种测量终态。

## 2026-08-08 14:47 - DSP 对抗反例修正
